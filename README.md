# MORPHO — Day 1

A full-viewport React + Tailwind birthday countdown page.

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL.

## Customize

The Day 1 letter is in `src/main.jsx`. Replace the letter text, "Dear you," and the closing with your own message.

The butterfly footage is loaded from the provided Supabase asset URL.
